Mini-Phyling V2

Mini-Phyling V2

Présentation

Un Mini-Phyling, c’est 20g d’électronique conçus pour s’intégrer sur tous les équipements existants. Il enregistre en local ou renvoie les données en temps réel en Bluetooth, c’est l’outil polyvalent et miniature.

Tous les Mini-Phyling à partir du 362 sont en V2.

Caractéristiques techniques

CaractéristiqueValeur
Dimensions57x34x11 mm
Poids20g
Autonomie13h (sans capteur additionnel)
ConnectivitéBluetooth (BLE)
Fréquence d'échantillonnageJusqu'à 200 Hz
Capteurs embarquésAccéléromètre 3 axes, Gyroscope 3 axes, Magnétomètre 3 axes

Prise en main rapide

Appuyez 0.5s sur le bouton ON/OFF pour l’allumer, la LED passe au vert. Il se connecte au Maxi-Phyling automatiquement. Pour lancer un enregistrement en local sur carte SD, appuyez sur le bouton REC, la LED passe alors au bleu. L’enregistrement sur carte SD et l’envoi des données en Bluetooth sont indépendants.

Code couleur de la LED

  • ⚪ Blanc : le Mini-Phyling s’initialise ou s’éteint
  • 🟢 Vert : le Mini-Phyling est prêt à lancer un enregistrement
  • 🔵 Bleu : le Mini-Phyling enregistre des données sur carte SD
  • 🟡 Jaune : le Mini-Phyling est en mode USB
  • 🔴 Rouge : il y a un problème indiqué par le nombre de clignotements avant extinction
    • x2 : Erreur dans la config (module invalide, fichier mal formaté, etc.)
    • x4 : Carte SD pleine : vous pouvez la vider manuellement en mode USB ou dans le mode hotspot
    • x5 : Erreur de fichier de paramétrage (fichiers Device, Calibration, etc.)
    • Pas de clignotement : Autre problème
  • Clignotement vert rapide : le Mini-Phyling n'est pas connecté en Bluetooth
  • Clignotement rouge de 0.5s toutes les 5s : il reste moins de 15% de batterie
  • Rouge à l’allumage avant l’initialisation : il y a une erreur d’initialisation, il faut éteindre et rallumer le Mini-Phyling. Si le problème persiste, il faut vérifier les fichiers de configuration (voir mode USB).

Allumage et enregistrement

2 boutons se trouvent sur le Mini-Phyling : un bouton ON/OFF et un bouton REC.

  • Pour allumer ou éteindre le Mini-Phyling, restez appuyé 0.5s sur le bouton ON/OFF
  • Pour lancer ou arrêter un enregistrement, appuyez sur le bouton REC
  • Un appui long de 3s sur le bouton ON/OFF lorsque le Mini-Phyling est éteint permet de passer en mode USB pour accéder au fichier d'enregistrement et à la configuration du Mini-Phyling.

Une sauvegarde automatique des données toutes les minutes garantit qu’en cas de coupure par manque de batterie ou d’extinction du boîtier, seule la dernière minute d’enregistrement est perdue.

Charge

Le Mini-Phyling se charge uniquement avec le cordon d’alimentation magnétique fourni par Phyling. Une LED à côté du chargeur indique quand le Mini-Phyling charge et s’éteint à la fin du chargement.

Centrale inertielle (IMU)

L’orientation du boîtier est la même que pour le Maxi-Phyling (cf. section Maxi-Phyling IMU). Il peut renvoyer jusqu’à 6 données (3 accéléromètres et 3 gyroscopes) en fonction de sa configuration.

Récupération des données

En Bluetooth, les données sont envoyées en temps réel au Maxi-Phyling.

Mode USB & transfert Cloud

Relier le cordon d'alimentation du Mini-Phyling à un port USB-A d'un ordinateur. À partir du Mini-Phyling éteint, appuyez longuement sur le bouton ON/OFF jusqu'à obtenir la LED jaune. Le Mini-Phyling est alors en mode USB. L'ordinateur va détecter le Mini-Phyling comme une clé USB. Il est possible d'accéder à tous les enregistrements stockés dessus. Allez dans le dossier DATA/ pour retrouver un enregistrement.

Pour sortir du mode USB, redémarrez le Mini-Phyling.

Pour importer une activité sur l'application Cloud de Phyling, il suffit de se rendre sur l'application depuis un navigateur web à l’adresse app.phyling.fr et de se connecter avec identifiant et mot de passe. Dans l'application, allez dans l’onglet "Données", cliquez sur le bouton "Importer" (forme de nuage) au-dessus du tableau de données et sélectionnez le fichier txt de l'enregistrement à importer.

Configuration

Les Mini-Phyling sont configurés par Phyling avant livraison. La configuration se trouve dans le fichier CONFIG/CONFIG.JS dans le mode USB. Pour toute question pour reconfigurer un Mini-Phyling, contactez l’équipe Phyling.
