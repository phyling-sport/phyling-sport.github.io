Problèmes fréquents

Mon Mini-Phyling ou mon Maxi-Phyling ne s’allume plus

Inutile de taper dessus : mettez le boîtier à charger et essayez de le rallumer 30 minutes après. Si aucun indicateur de charge ne s’allume, contactez l’équipe Phyling.

Si le capteur démarre et plante directement avec une LED rouge qui clignote, vérifiez à quelle erreur cela correspond pour les Maxi-Phyling ou les Mini-Phyling.

Je ne trouve pas le réseau Wi-Fi de mon Hub
  • Vérifiez que votre Hub n’est pas passé en mode Mallette (LED qui clignote toutes les 10 secondes).
  • Redémarrez le Wi-Fi de votre ordinateur ou vérifiez sur un autre appareil si le réseau Wi-Fi est présent ou non.
Quand je tape l’adresse IP, mon ordinateur ne trouve pas l’application
  • Vérifiez que votre ordinateur est bien connecté au réseau Wi-Fi du Hub.
  • Vérifiez également que l’adresse IP de connexion est la bonne (http://192.168.1.42).

Si le problème n’est pas résolu, redémarrez le Hub.

Je n'arrive pas à accéder à l'application Cloud

Ce problème peut avoir plusieurs origines :

  • Vérifiez que l'adresse de l'application est bien https://app.phyling.fr
  • Vérifiez que vous êtes bien connecté à Internet (par exemple en allant sur www.phyling.fr)
  • Si le problème persiste, essayez d'ouvrir l'application avec un autre navigateur web (par exemple : Firefox, Safari, Microsoft Edge, Google Chrome).

Si le problème est lié au navigateur, alors il faut peut-être vider le cache du navigateur pour qu'il puisse de nouveau ouvrir l'application.

Mon Maxi-Phyling n'apparaît pas sur l'application
  • Vérifiez la configuration Wi-Fi du Maxi-Phyling en mode Hotspot. Assurez-vous que le paramètre enabled du réseau du Hub est à true, que le mot de passe est correct, et que les autres réseaux Wi-Fi Phyling_Hub_xx ont le paramètre enabled à false. Vous pouvez accéder au mot de passe du Hub depuis l'application dans l'onglet Réglages -> Hubs : cliquez sur le stylo de modification de votre hub pour visualiser son mot de passe.
  • Vérifiez que le Maxi-Phyling est bien activé dans l'application. Allez dans l'onglet Réglages -> Capteurs Phyling et assurez-vous que le capteur est bien présent et activé. Si ce n'est pas le cas, mettez à jour votre base de données. Si cela ne fonctionne toujours pas, envoyez un mail à contact@phyling.fr.
Je ne retrouve pas un enregistrement d’un Maxi-Phyling

Les derniers enregistrements (hors scénarios) arrivent dans le tableau des nouvelles données à associer (bouton NEW dans l'onglet Données de l'application).

Filtrez les données par Maxi-Phyling et vérifiez tous les fichiers qui ne sont pas à l’heure. N'hésitez pas à rafraîchir la page. Les enregistrements longs peuvent prendre quelques minutes à charger dans l’application. N'hésitez pas à attendre quelques minutes.

Je ne peux pas visualiser mes données, il y a un point d’exclamation !

Cela signifie que l’analyse de l’enregistrement a échoué et qu’il y a peut-être un problème avec les données. Il est possible de relancer l’analyse avec un autre sport. Utilisez le sport "Défaut" pour visualiser les données brutes. N'hésitez pas à envoyer les données à l’équipe Phyling pour voir d’où vient le problème.

Le fichier de calibration ne veut pas se mettre à jour sur l'application

Vérifiez que le fichier est bien conforme à la norme JSON. ChatGPT peut vous aider à bien formater le fichier.

L'erreur la plus commune est l'ajout d'une virgule à la fin du dernier élément d'une liste :

{
  "<moduleName>": {
    "<varName 1>": {
      "coef": 0.333,  <-- virgule obligatoire ici
      "offset": 0  <-- pas de virgule ici
    },  <-- virgule obligatoire ici
    "<varName 2>": {
      "coef": 0.333,
      "offset": 0
    }  <-- pas de virgule ici
  }
}
La calibration ne s'applique pas

Vérifiez que le nom du module et le nom de la voie de mesure sont exactement les mêmes que dans la configuration du Maxi-Phyling. Vérifiez que le fichier de calibration est bien dans le format ci-dessus.

Pour tous les problèmes

N'hésitez pas à redémarrer le Hub et les Maxi-Phyling en cas de bug.

Si le problème persiste ou pour toute question, envoyez un mail à contact@phyling.fr
