Connexion filaire et Récupération des Données

1. Connexion USB (Mode USB)

Pour accéder aux fichiers directement sur votre ordinateur :

  1. Assurez-vous que le Maxi-Phyling est éteint.
  2. Maintenez le bouton On appuyé pendant 5 secondes.
  3. Connectez le câble USB.

Le dossier MAXI_XXX apparaîtra sur votre ordinateur.
Vos fichiers se trouvent dans le dossier DATA (nommés par date/heure/numéro de record).

2. Importation sur l'Application (app.phyling.fr)

  1. Connectez-vous sur app.phyling.fr.
  2. Allez dans l’onglet DONNÉES.
  3. Cliquez sur Importer un fichier (icône nuage).
  4. Sélectionnez le fichier depuis le dossier du Maxi-Phyling connecté en USB.

Réglage sans fil et sans application (Hotspot et WiFi)

Connexion Directe (Hotspot)

Pour configurer l'appareil :

  1. Sur votre smartphone ou PC, connectez-vous au réseau WiFi :
    Maxi-Phyling_XXX
  2. Ouvrez un navigateur et tapez l’adresse :
    192.168.1.42

Configuration WiFi

Depuis l’interface 192.168.1.42 :

  1. Allez dans Réseaux WiFi.
  2. Insérez la configuration JSON (SSID + mot de passe de votre connexion Internet + serveur de connexion)
    pour permettre au boîtier d’envoyer automatiquement les données.

Faire un enregistrement via l’Application Cloud Phyling

Temps Réel

  • Onglet REALTIME → cliquez sur START / STOP pour contrôler l’enregistrement à distance.

Analyse

  • Onglet DATA
  • Trouvez votre fichier dans la liste NEW (bouton bleu NEW).
  • Associez votre fichier via la double flèche.
  • Sélectionnez ensuite le fichier pour :
    • visualiser les courbes
    • analyser les performances
    • exporter un PDF
    • exporter un fichier .CSV

Chargement

  • Utilisez le câble magnétique fourni.
  • Batterie faible : moins d’une heure d’autonomie restante.
  • En charge : connectez le câble USB à une source d’alimentation.
