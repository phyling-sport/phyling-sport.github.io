Introduction

Introduction

General overview

The Phyling solution is complete and fits seamlessly into sports, research or industrial environments. Our solution collects and synchronizes data from a large number of embedded sensors. Data can be visualized and processed directly in our application. It can also be exported in CSV format for analysis with your own software.

Quick start

Mini-Phyling units used alone or with an external sensor are already preconfigured. Simply turn them on (On button) and they start sending data (or start a local recording on the SD card, if they have one, with the Rec button).

For a preconfigured Maxi-Phyling, simply turn it on (On button) and start a recording (Rec button). The connection of the Maxi-Phyling to the Mini-Phyling, the Maxi-Hub or the Nano-Phyling is automatic.

For a Phyling-LTE, turn on the sensor with the switch, press the button to start recording, and the data is sent in real time over LTE-M to the Phyling cloud platform.

Using the Phyling acquisition units is simple, with:

  • An ON/OFF switch and a multifunction button (or 2 buttons for older models)
  • An LED with a color code according to the unit's status:
    • 🟢 Green = Ready to use
    • 🔵 Blue = Recording in progress
    • Blinking = Warning, one or more sensors are not connected (see the details of each unit)

To access the online application, use this address: https://app.phyling.fr. On the Maxi-Hub, connect to the Hub's Wi-Fi network and enter the address http://192.168.1.42 in your favorite web browser.

The Phyling application lets you start and stop recordings on one or more Maxi-Phyling units, and also view data in real time. Once the recording is finished, the data is processed with specific analysis modules and can be visualized. PDF reports can also be generated automatically.
