Phyling-Live V2

Phyling-Live V2

Présentation

Le Phyling-Live V2, carte Phyling dédiée (PCB 60.2), est un capteur IoT complet optimisé pour l'envoi de flux de données en temps réel via connectivité LTE-M ou WiFi. Conçu pour les applications sportives et d'analyse du mouvement, il combine une IMU 9 axes avec GPS et un système de buffering intelligent pour la continuité de service hors ligne.

Caractéristiques techniques

CaractéristiqueValeur
Batterie1 800 mAh
Autonomie≈ 40 h en enregistrement WiFi (voir Batterie et autonomie)
ConnectivitéLTE-M, WiFi, Bluetooth (BLE)

Prise en main rapide

Allumage

Le Phyling-Live dispose d'un interrupteur ON/OFF (switch) et d'un bouton unique multifonction :

  • Appui court (< 1s) sur l'interrupteur : allumer / éteindre le capteur.
    • LED verte : prêt à démarrer.
  • Appui court sur le bouton : démarrer / arrêter un enregistrement (record).
    • LED bleue : enregistrement en cours.

Connectivité et synchronisation

Une fois allumé et en enregistrement, le Phyling-Live envoie en temps réel les données capteur via LTE-M ou WiFi vers la plateforme Phyling. Vous pouvez visualiser et configurer le capteur via :

  • Application cloud Phyling : https://app.phyling.fr
  • API Phyling : https://docs.phyling.fr/dev/

Récupération hors ligne

Si le réseau LTE-M n'est pas disponible, le capteur garde en mémoire une partie du flux de données (buffer). À la restauration de la connexion, il renvoie automatiquement les données en attente.

Code couleur de la LED

Une LED sert à donner toutes les indications sur l'état du Phyling-Live :

  • ⚪ Blanc : le Phyling-Live s'initialise ou s'éteint
  • 🟢 Vert : le Phyling-Live est prêt à lancer un enregistrement
  • 🔵 Bleu : le Phyling-Live enregistre des données
  • 🟣 Violet : le Phyling-Live est en mode hotspot (configuration WiFi)
  • 🔴 Rouge : il y a un problème indiqué par le nombre de clignotements avant l'extinction
    • x2 : Erreur dans la config (module invalide, fichier mal formaté, etc.)
    • x3 : GPS non fonctionnel (s'il n'est pas indispensable, désactivez-le ou mettez "important": false dans sa configuration)
    • x4 : Mémoire interne pleine (non fatal)
    • x5 : Erreur de fichier de paramétrage (fichiers Device, Wifi, Calibration, etc.)
    • x6 : Lors d'une mise à jour, une erreur est survenue (clignotement vert si elle a fonctionné)
    • Pas de clignotement : Autre problème
  • Clignotement vert avec des extinctions de 0.25s toutes les 5s : un des capteurs définis comme "importants" n'est pas connecté
  • Flash vert bref toutes les 3 s : le Phyling-Live est en veille (idle_sleep)
  • Clignotement vert rapide (extinctions de 0.25s toutes les 0.5s) : pas de connexion réseau
  • Clignotement rouge de 0.5s toutes les 5s : il reste moins de 15% de batterie
  • Rouge à l'allumage avant l'initialisation : il y a une erreur d'initialisation, il faut éteindre et rallumer le Phyling-Live

Charge

Le Phyling-Live se charge via port USB-C avec un adaptateur standard. Une LED rouge de charge indique l'état de charge.

Temps réel & Flux de données

Le Phyling-Live est optimisé pour le flux temps réel. Contrairement aux autres capteurs Phyling qui stockent localement, il privilégie l'envoi immédiat vers la plateforme cloud Phyling.

Visualisation en temps réel

Via l'application Phyling ou l'API temps réel, les données s'affichent instantanément.

Gestion de la configuration

Toute la configuration (fréquence d'échantillonnage, seuils d'alerte, modules actifs) se fait depuis :

  • L'application cloud app.phyling.fr
  • L'API Phyling

Choisir son mode réseau

Le Phyling-Live peut fonctionner en WiFi seul (wifi), en LTE-M seul (lte) ou en WiFi et LTE ensemble (dual, le LTE prenant le relais quand le WiFi manque). Le changement de mode demande un redémarrage.

  • Site équipé en WiFi : wifi, commandes en moins d'une seconde.
  • Zone sans WiFi : lte, commandes au plus à l'intervalle de réveil (10 s par défaut), à régler selon l'autonomie visée.
  • Parcours avec trous de WiFi : dual.

Le niveau d'itinérance, la bande WiFi et les fréquences se règlent à chaud. Voir Profils : réseau, roaming et fréquences.

Mode hotspot

Le mode hotspot permet de configurer la connexion WiFi du Phyling-Live via un portail web accessible directement depuis votre appareil (téléphone, tablette ou ordinateur).

Activation du mode hotspot

  1. Appuyez 3 secondes sur le bouton ON/OFF du capteur.
  2. La LED violette s'allume pour signaler que le mode hotspot est actif.
  3. Un réseau WiFi nommé Phyling-Live XXX apparaît : connectez-vous à ce réseau.
  4. Accédez au portail de configuration (l'URL s'affiche automatiquement, ou saisissez 192.168.1.42 dans votre navigateur).
  5. Vous pouvez modifier tous les fichiers de configuration (wifi, config, etc.).
  6. Le Phyling-Live redémarre et se connecte au réseau. La LED redevient verte (prêt).

Récupération et export des données

La récupération et l'export des données se font uniquement via l'API Phyling en temps réel. Le flux capteur est transmis en continu et consommé directement par votre application via l'API.

Batterie et autonomie

Autonomie estimée du Phyling-Live V2 (batterie 1 800 mAh) :

UsageAutonomie
Enregistrement en WiFi≈ 40 h
Enregistrement en LTE≈ 30 h
Enregistrement en dual (WiFi + LTE)≈ 30 h
Veille (idle_sleep)≈ 7 jours

Ces valeurs correspondent à des conditions réalistes (GPS actif, capteurs BLE connectés, LED allumée, envoi chaque seconde, réseau variable) : l'autonomie réelle dépend de la configuration et de la couverture.

La veille (idle_sleep) est un mode économe : moins de réactivité, LED en flash bref, GPS et capteurs BLE coupés. Le Phyling-Live y passe seul après 30 min sans activité (durée réglable, veille automatique désactivable dans la section « Veille » des réglages avancés de la config) ; on peut aussi l'y mettre depuis l'application (menu ⋮ → Alimentation → « Mettre en veille »). Un appui sur REC (sans lancer d'enregistrement), un appui sur ON/OFF ou le bouton « Réveiller » de l'application le réveille ; lancer un enregistrement depuis l'application le réveille aussi.

  • Charge complète via USB-C : ~2-3 heures
  • Clignotement rouge : batterie < 15%

Optimisation de l'autonomie

Pour prolonger la batterie :

  • Baissez la fréquence d'échantillonnage si la précision le permet
  • Réduisez la fréquence d'envoi des données (configurée dans l'app)
  • Désactivez les modules non utilisés
