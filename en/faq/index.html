Frequently Asked Questions

My Mini-Phyling or Maxi-Phyling no longer turns on

There is no need to hit it: put the unit on charge and try to turn it on again 30 minutes later. If no charging indicator lights up, contact the Phyling team.

If the sensor starts and immediately crashes with a flashing red LED, check which error it corresponds to for the Maxi-Phyling or the Mini-Phyling.

I cannot find my Hub's Wi-Fi network
  • Check that your Hub has not switched to Case mode (LED blinking every 10 seconds).
  • Restart your computer's Wi-Fi or check on another device whether the Wi-Fi network is present or not.
When I type the IP address, my computer cannot find the application
  • Check that your computer is connected to the Hub's Wi-Fi network.
  • Also check that the connection IP address is correct (http://192.168.1.42).

If the problem is not solved, restart the Hub.

I cannot access the Cloud application

This problem can have several causes:

  • Check that the application address is https://app.phyling.fr
  • Check that you are connected to the Internet (for example by going to www.phyling.fr)
  • If the problem persists, try opening the application with another web browser (for example: Firefox, Safari, Microsoft Edge, Google Chrome).

If the problem is browser-related, you may need to clear the browser cache so that it can open the application again.

My Maxi-Phyling does not appear in the application
  • Check the Maxi-Phyling's Wi-Fi configuration in Hotspot mode. Make sure the Hub network's enabled parameter is set to true, that the password is correct, and that the other Phyling_Hub_xx Wi-Fi networks have their enabled parameter set to false. You can find the Hub's password in the application under Settings -> Hubs: click the edit pencil of your hub to view its password.
  • Check that the Maxi-Phyling is enabled in the application. Go to Settings -> Phyling Sensors and make sure the sensor is present and enabled. If it is not, update your database. If it still does not work, send an email to contact@phyling.fr.
I cannot find a Maxi-Phyling recording

The latest recordings (excluding scenarios) arrive in the table of new data to be associated (NEW button in the Data tab of the application).

Filter the data by Maxi-Phyling and check all the files whose time is not correct. Do not hesitate to refresh the page. Long recordings can take a few minutes to load in the application. Do not hesitate to wait a few minutes.

I cannot view my data, there is an exclamation mark!

This means that the analysis of the recording failed and that there may be a problem with the data. It is possible to restart the analysis with another sport. Use the "Default" sport to view the raw data. Do not hesitate to send the data to the Phyling team so they can find out where the problem comes from.

The calibration file will not update in the application

Check that the file complies with the JSON standard. ChatGPT can help you format the file correctly.

The most common error is adding a comma after the last element of a list:

{
  "<moduleName>": {
    "<varName 1>": {
      "coef": 0.333,  <-- comma required here
      "offset": 0  <-- no comma here
    },  <-- comma required here
    "<varName 2>": {
      "coef": 0.333,
      "offset": 0
    }  <-- no comma here
  }
}
The calibration is not applied

Check that the module name and the measurement channel name are exactly the same as in the Maxi-Phyling configuration. Check that the calibration file is in the format shown above.

For all problems

Do not hesitate to restart the Hub and the Maxi-Phyling units if you run into a bug.

If the problem persists or for any question, send an email to contact@phyling.fr
