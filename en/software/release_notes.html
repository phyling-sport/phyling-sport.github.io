Release notes

Release notes

This section presents the new features, improvements and bug fixes for each update of our application.

v7.0.6

Update of 10/09/2026

New features

  • [LTE] 🔥 Added a Wi-Fi operating mode and a hotspot mode for configuration
  • [LTE] 🔥 Added the IMU module and real-time yaw, pitch and roll calculations
  • [LTE] Added calibration modules built into the sensor, which can be launched from the cloud application
  • [LTE] Added connections to commercially available heart rate sensors and power meters
  • [APP] 🔥 Set up a webhook system for OAuth applications, to send updates about recordings and users

Improvements

  • [APP] Automatic detection of errors in JSON configuration files
  • [APP] Improved the sensor configuration menu
  • [APP] Improved the Wi-Fi network configuration menu
  • [MAXI] Added a system to recover real-time data after a connection loss
  • [MAXI] Improved automatic Wi-Fi network switching when the connection is weak and several networks are available
  • [APP] Added filters in the Phyling sensor management menu, with synchronization with Meca sensors

Bug fixes

  • [MAXI] Improved reliability with several BLE sensors connected
  • [MAXI] Various bug fixes
  • [APP] Fixed the tare calibration for modules with a 3D calibration (3-axis platform, IMU, etc.)

v7.0.5

Update of 07/07/2026

New features

  • [LTE] 🔥 Created a new Phyling-LTE device type for streaming over 4G LTE-M
  • [APP] 🔥 Added real-time and analysis polar plots for the Phyling crankset and Pi3D
  • [MAXI] Added an automatic BLE scan system on the Maxi-Phyling

Improvements

  • [MAXI] New powermeter module to retrieve power/cadence data from external sensors over BLE.
  • [MAXI] New xsens module to connect an xsens pod to the Maxi-Phyling
  • [APP] Improved UX on app.phyling.fr: you now have to press Esc twice to leave a recording visualization, and closing the visualization with Esc is prevented while a submenu is open.
  • [APP] Added a special crankset calibration to set up a top-turn and tare the forces
  • [ANALYSE] Added a selection_num column in CSV exports to give the corresponding selection number
  • [ANALYSE] Integrated pressure mats into the CSV data export.

Bug fixes

  • [APP] Fixed a file upload bug in admin
  • [APP] Fixed device filters in admin
  • [APP] Fixed a lost file bug when re-downloading data from a Maxi-Phyling
  • [APP] Improved API latency for routes with filters
  • [APP] Improved database synchronization speed
  • [APP] Data download from the Maxi-Phyling is now automatically paused during recordings
  • [ANALYSE] Fixed a bug with GPS data (half-invalid data)
  • [APP] When updating the calibration of a V2 Crankset from a Garmin/Polar watch, the calibration was not properly reloaded from the application
