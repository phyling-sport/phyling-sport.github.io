Maxi-Phyling

Maxi-Phyling

Overview

This is the heart of Phyling technology: a unique, versatile unit that records all your data at high frequency. Compact, it fits anywhere. Its processing power allows it to send and analyze data in real time.​

Technical specifications

SpecificationValue
Dimensions77x49.5x19.30 mm
Weight100g
Battery life9h
ConnectivityWifi, Bluetooth (BLE)
Sampling frequencyUp to 1kHz
Embedded sensors3-axis accelerometer, 3-axis gyroscope, 3-axis magnetometer, multi-band GPS (10Hz)
Water resistanceIPX7

Quick start

Press the ON button for 0.5 seconds to turn it on; the LED turns green. To start a recording, press the REC button; the LED then turns blue.

Once turned on, the Maxi-Phyling can be fully controlled with the Phyling application from a Maxi-Hub or from the Phyling cloud application https://app.phyling.fr.

LED color code

An LED provides all the information about the state of the Maxi-Phyling:

  • ⚪ White: the Maxi-Phyling is initializing, shutting down or is in Recovery mode (after a record).
  • 🟢 Green: the Maxi-Phyling is ready to start a recording
  • 🔵 Blue: the Maxi-Phyling is recording data
  • 🟣 Purple: the Maxi-Phyling is in Hotspot mode
  • 🟡 Yellow: the Maxi-Phyling is in USB mode
  • 🔴 Red: there is a problem, indicated by the number of blinks before shutdown
    • x2: Configuration error (invalid module, badly formatted file, etc.)
    • x3: GPS not working (if it is not essential, disable it or set "important": false in its configuration)
    • x4: SD card full: you can empty it manually in USB mode or in Hotspot mode
    • x5: Settings file error (Device, Wifi, Calibration files, etc.) or failure of an automatic sensor calibration (green blink if it succeeded)
    • x6: An error occurred during an update (green blink if it worked)
    • No blinking: Other problem
  • Green blinking with 0.5s off every 3s: one of the sensors defined as "important" is not connected (see in the settings how to define a sensor as important)
  • Red blinking for 0.5s every 5s: less than 15% battery remaining
  • Red at startup before initialization: there is an initialization error; turn the Maxi-Phyling off and on again

Power on, recording and usage modes

The Maxi-Phyling has 2 buttons: an ON/OFF button and a REC button.

  • To turn the Maxi-Phyling on or off, hold the ON/OFF button for 0.5s
  • To start or stop a recording, press the REC button
  • A 3s long press on both ON/OFF and REC buttons while the Maxi-Phyling is off switches to Hotspot mode
  • A 3s long press on the ON/OFF button while the Maxi-Phyling is off switches to USB mode

Recovery mode

Recovery mode allows you to retrieve the data of a Mini-Phyling that failed to send all its data to the Maxi-Phyling.

Conditions to activate recovery mode:

  • The Maxi-Phyling and the Mini-Phyling are at least on version v6.6.6.
  • The Mini-Phyling have "Recovery" mode enabled in their configuration ("useRecovery": true after use_ble).

How it works: at the end of a recording, the Maxi-Phyling switches to recovery mode (WHITE LED), and all Mini-Phyling with recovery mode enabled send their data to the Maxi-Phyling. Once the data is received, the Maxi-Phyling exits recovery mode and returns to normal mode (GREEN LED).

During recovery mode, if you press the REC button, the Maxi-Phyling returns to normal mode (GREEN LED) and the Mini-Phyling stop sending their data.

Charging

The Maxi-Phyling charges only with the magnetic power cable supplied by Phyling. A white LED lit next to the charger indicates that the Maxi-Phyling is charging; it turns off when the Maxi-Phyling is fully charged.

Inertial measurement unit (IMU)

The IMU returns 6 values (accelerations and angular velocities for the 3 directions). The axes of the unit are defined in the following diagram. For all applications where positioning matters (notably rowing and kayaking), make sure to place the unit with the X axis pointing in the direction of travel.

Data retrieval

On a Maxi-Hub, data is automatically downloaded to the Phyling Hub when the Maxi-Phyling connects to it and a recording is finished. It appears in the "New data" table (see the Data tab). This data must then be associated with one or more athletes, optionally adding other information such as an exercise and a comment.

On the Phyling cloud application https://app.phyling.fr, the Maxi-Phyling automatically uploads its data as soon as the recording ends if it is connected to a WiFi network preconfigured here. It appears in the "New data" table (see the Data tab). This data must then be associated with one or more athletes, optionally adding other information such as an exercise and a comment.

USB mode & Cloud transfer

With the Maxi-Phyling off, press and hold the ON/OFF button until the LED turns yellow. The Maxi-Phyling is then in USB mode. Simply connect the Maxi-Phyling power cable to a USB-A port and the computer will detect the Maxi-Phyling as a USB drive. You can access all the recordings stored on it. Go to the data/ folder to find a recording named after its start time.

To exit USB mode, restart the Maxi-Phyling.

To import an activity into the Phyling Cloud application, simply go to the application from a web browser at app.phyling.fr and log in with your username and password. In the application, go to the "Data" tab, click the "Import" button above the data table and select the recording's txt file to import.

Configuration

The Maxi-Phyling can be configured through several configuration files stored in its memory and accessible from Hotspot mode or via the application. We recommend configuring from the application, which is detailed here.

Calibration

The sensor calibration of a Maxi-Phyling is also defined in a configuration file. Find more information about the calibration file, the calibration procedure in the application and the different types of calibration here.

Hotspot mode

To configure a Maxi-Phyling, and in particular the Hub it must connect to, there is a Hotspot mode. With the Maxi-Phyling off, press the 2 buttons ON/OFF and REC at the same time for 3s. The LED turns purple. The Maxi-Phyling then broadcasts a Wifi network bearing its name and number (for example: Maxi_Phyling_42). Connect with the password "hellophyling", then enter the address http://192.168.1.42 in a browser to access the configuration interface.

Wifi network configuration

For a connection through a Maxi-Hub, the Maxi-Phyling must connect to the Maxi-Hub's Wi-Fi network to transmit their data and make it visible in the application. The networks they are allowed to connect to are listed in the Wi-Fi Networks section of Hotspot mode. To add a network, add a new entry to the list or edit an existing network. Don't forget to update before leaving the interface.

For a connection to the Cloud application, you need a Maxi-Phyling V3 running version V7.0.0 or higher. Put the Maxi-Phyling in Hotspot mode and enter one or more Wi-Fi networks, then select app.phyling.fr as the connection server. Save the changes and restart the Maxi-Phyling. It will automatically connect to the first known Wi-Fi network it finds.

Note: Maxi-Phyling units can connect to a phone's connection sharing (hotspot). Make sure to check the "Maximize Compatibility" option on iOS or enable the "2.4 GHz" option on Android.

Change the Maxi-Phyling configuration

Each Maxi-Phyling has its own configuration with a list of modules (IMU, GPS, heart rate, etc.). In Hotspot mode, you can change the configuration in the "Config" menu.

Warning

This configuration mode using the raw file is risky: some configurations may not be understood by the Maxi-Phyling and prevent it from restarting properly.
Before changing the configuration, contact the Phyling team to avoid applying an incorrect configuration.

Add a heart rate sensor or a Mini-Phyling to the configuration

To add heart rate sensors or a Mini-Phyling, this can be done from the hotspot / Config menu. You can run a Bluetooth sensor scan and then simply copy/paste the configuration of the module to add.

Warning

For some heart rate sensors, the Maxi-Phyling may not detect their name. In that case, the sensor will be called "NO NAME", and you will only see its MAC address.

Warning

Make sure to respect the JSON format in the configuration.

Empty a Maxi-Phyling's memory

Even once the data has been downloaded to the application, it remains stored in the Maxi-Phyling. To avoid saturating the memory, it is best to delete all the data from time to time. To do so, click the "Delete all records" button; the LED turns white. Then wait until it turns purple again. This operation can take a very long time if there is a lot of data.

Warning

For your Maxi-Phyling to work properly, do not modify the other tabs of Hotspot mode.

Update via Hotspot mode

Updating a Maxi-Phyling brings fixes and new features. Update files are made available to Managers as soon as they are released on the Cloud application.

Note

Updating a Maxi-Phyling can also be done directly from the application in the Real time tab (see Maxi-Phyling configuration).

On the Phyling Cloud application

The update is available in the Settings tab, under the "Releases" menu. To get the latest version, download the one with the highest numbers (for example, version v6.6.4 is more recent than version v6.6.3). A .bin file is available in your download folder.

On the Maxi-Phyling Hotspot mode

  1. Click "Update code".
  2. Import the .bin update file.
  3. The Maxi-Phyling updates and restarts automatically.
